# 機器人模擬賽 賽務控制台

一台電腦跑伺服器，工作人員用手機連線，完成一場機器人模擬賽的賽務：賽程與檢錄、九宮格計分、比賽計時、名次與淘汰賽配對、觀賽畫面、直播字卡。2026-11-15 的 **TEL Robot Combat 跨校模擬賽**（中央大學 BoltNut）實際使用過，下次比賽改設定檔和賽程就能重複使用。

- 只需要 **Node.js 24 以上**（使用內建的 `node:sqlite`），**沒有任何 npm 套件**，不必 `npm install`。
- 手機透過 **Tailscale Funnel** 連進來，不必裝 App；也可以只在區網或本機用。
- 交接給 AI agent 時，請它先讀 [AGENTS.md](AGENTS.md)。比賽當天的操作清單在 [docs/event-day-checklist.md](docs/event-day-checklist.md)，2026 年比賽期間的修改紀錄在 [docs/CHANGELOG-2026.md](docs/CHANGELOG-2026.md)。

## 功能一覽

| 功能 | 說明 |
|---|---|
| 賽程、檢錄、任務 | 時程表、隊伍到場／檢錄、工作分工、異動與備案，全部可多人同時編輯，每次修改都留歷史 |
| 九宮格計分 | 手機點擊計分（九宮格、上方三個小洞、黃牌、救援卡），停手 0.4 秒自動同步；伺服器依規則重新計分 |
| 比賽計時 | 調整準備 90 秒 → 正式比賽 3 分鐘（前 60 秒 AI 自主）、晉級隊維修 5 分鐘、機器人靜止倒數 30 秒；以伺服器時間為準 |
| **主審指定上場** | 排名賽順序不固定：主審在計時頁選「誰在場上」，計分員的計分畫面自動跳到那一場；淘汰賽由主審手動選兩隊 |
| 自動名次 | 排名賽全部確認後，依總分與同分規則自動填入名次；完全同分留白給主審抽籤 |
| 淘汰賽配對 | 四隊：第 1 vs 第 4、第 2 vs 第 3 → 冠軍賽；五隊：多一場附加賽（第 4 vs 第 5）。主審可改 |
| 未出賽／移除場次 | 裁判判決選「未出賽」排最後、對手不戰而勝；主審可把整場從賽程移除（可復原） |
| 觀賽畫面 | 檢視通行碼登入後只看得到這頁：現在／下一場、即時計分看板（暫定）、名次、對戰、冠軍、流程 |
| 直播字卡 | 攝影權限登入後滿版顯示比分字卡（綠幕／透明背景），OBS 用免登入連結 `/obs/<攝影通行碼>` |
| 比賽音效 | 開始、第 60 秒切換手動、剩 30 秒、結束；觀賽畫面、主審控制台、直播字卡都會播 |
| 成績 | 依實際上場順序列出；CSV 匯出（Excel 可直接開、已防公式注入）；名次與分數矛盾時警告 |
| 安全 | 每人一組通行碼、可停用／重新產生／踢掉裝置；輸錯過多暫停；對外埠一律要登入 |

## 快速開始

```powershell
node -v                      # 需要 v24 以上
node scripts/fetch-sounds.mjs  # 第一次：下載比賽音效（不下載也能用，只是沒聲音）
node server.mjs              # 啟動
```

開啟 http://127.0.0.1:3000 ，**本機免登入、擁有全部權限**。第一次啟動會自動建立資料夾、資料庫和檢視通行碼，終端機會印出資料庫路徑與檢視碼。

### 讓手機連線（Tailscale）

```powershell
$env:PUBLIC_PORT = '3080'
node server.mjs                               # 3080 是給 Tailscale 轉進來的埠，每個請求都要登入
tailscale funnel --bg --https=10000 3080      # 公開到網際網路（手機不必裝 Tailscale）
# 或：tailscale serve --bg --https=10000 3080  只給已加入 tailnet 的裝置
```

網址是 `https://<電腦名稱>.<tailnet>.ts.net:10000/`。Funnel 只允許 443、8443、10000 三個埠。比賽結束後關閉：`tailscale funnel --https=10000 off`。

- **絕對不要把 Tailscale 指到 3000**（本機免登入埠）。伺服器偵測到代理標頭會直接拒絕，但不要依賴這一點。
- 主控電腦只綁 127.0.0.1，外人無法用「本機」身分連線。

### 開機自動啟動（Windows，選用）

`scripts\windows\run-tel.ps1` 是看門狗：伺服器結束 5 秒後自動重開、同時只跑一份、輸出寫到 `<資料夾>\logs\`。把 `scripts\windows\tel-console.cmd` 的**捷徑**放進「啟動」資料夾（Win+R → `shell:startup`），登入 Windows 後就會在背景啟動。專案路徑會自動偵測，不用改檔。

手動開的伺服器和看門狗只能二選一，同時開會搶 3000 埠。

## 權限與通行碼

| 權限 | 可以做什麼 | 給誰 | 怎麼取得 |
|---|---|---|---|
| 主裁判／總召（個人碼） | 全部：確認或撤回成績、操作計時、指定上場、選淘汰賽兩隊、移除場次、管理人員與登入裝置 | 主審、總召 | 本機開「人員與登入」建立 |
| 計分（個人碼） | 登錄計分明細、修改賽程／檢錄／任務 | 計分 A、計分 B、場務 | 同上 |
| 攝影（個人碼） | 只看直播字卡與觀賽畫面 | 攝影／直播 | 同上 |
| 檢視（共用一組） | 只看觀賽畫面 | 觀眾、各隊 | 首次啟動自動產生，存在 `<資料夾>\access-codes.json`；或用環境變數 `VIEW_CODE` 指定 |

- 個人碼 8 碼，登入時只要輸入通行碼，姓名和權限由名單帶入；登入維持 16 小時。
- **停用**某人：他所有裝置在 0.5 秒內登出、通行碼失效，可再「重新啟用」。**撤銷**某支手機：只踢那台。**重新產生**：舊碼立即失效。
- 同一來源 10 分鐘內輸錯 30 次會暫停 10 分鐘（校園 Wi-Fi 共用 IP，所以門檻不低）。
- 檢視碼外流：外人只能看。要換就改 `access-codes.json` 的 `view` 後重啟。

## 比賽當天怎麼用

完整清單見 [docs/event-day-checklist.md](docs/event-day-checklist.md)。核心流程：

1. **主審**在「比賽計時」頁的「上場」選單選隊伍（排名賽，順序不限）或場次（淘汰賽，另選 A／B 兩隊），按 **📣 指定上場**。計分員的計分畫面、觀賽畫面、直播字卡都會切到這一場。
2. 主審按 **① 調整準備 90 秒** → **② 開始比賽 3 分鐘**。第一次開始時系統自動記下「實際上場時間」。
3. **計分員**即時點擊計分。淘汰賽先在計分視窗上方選「我負責 A 方／B 方」，另一方會鎖住，避免點錯邊。
4. 比賽結束（或舉完成卡按 **✓ 完成**）後，主審複核、填簽認，把成績改成「已確認」。
5. 排名賽全部確認後名次自動帶入；淘汰賽依名次預設配對，主審可以改。

缺隊或臨時變動：

- **某隊沒來**：那隊的排名賽在「裁判判決」選 **未出賽** 並確認（排最後）；淘汰賽碰到時缺席方也選未出賽，對手不戰而勝。
- **某場不比了**：主審在「計分與影像」按 **移除場次**（可在「已移除的場次」復原）。
- **比賽中途的紅牌、失格、缺席**：選 **紅牌／失格／缺席**。

### 直播字卡（OBS）

- 新增「瀏覽器」來源，網址 `https://<網址>/obs/<攝影通行碼>`，寬 1920、高 1080。會自動登入並滿版顯示字卡，不用操作瀏覽器。
- 背景預設綠幕（#00B140，加「色彩鍵」去背）；網址加 `?bg=none` 透明、`?bg=dark` 深色。
- OBS 就在伺服器那台電腦上時，可直接用 `http://127.0.0.1:3000/overlay`（免登入、不經網路）。
- 只有「攝影」權限的通行碼能用 `/obs/` 連結；連結等於通行碼，外流時對攝影按「重新產生」。

### 比賽音效

| 時間點 | 音效 |
|---|---|
| 準備開始、比賽開始 | `start` |
| 比賽第 60 秒（切換手動） | `resume` |
| 剩 30 秒（準備與比賽） | `warning` |
| 時間到、按完成 | `end` |

觀賽畫面要先按右上角「🔇 開啟聲音」（瀏覽器規定）；主審與總召的控制台預設開啟，點一下畫面即啟用；直播字卡在 OBS 會自動播放。音效檔取得方式見 [sounds/README.md](sounds/README.md)。

## 下次比賽要改哪裡

| 要改的 | 位置 |
|---|---|
| 活動名稱、年份、日期、集合時間、主辦、字卡文字、企劃書版本 | **`worker/event.js`**（純文字，改完重啟） |
| 參賽隊伍（4 或 5 隊） | `worker/seed.js` 的預設名單，或環境變數 `TEL_TEAMS="甲,乙,丙,丁"` |
| 賽程時間、流程、任務、人員職務、備案文字 | `worker/seed.js` |
| 計分規則（每球分數、上限、連線、同分順序） | `worker/scoring.js`，先改 `tests/scoring.test.mjs` 的預期值 |
| 席位帶入、確認條件、自動名次、淘汰賽配對 | `worker/rules.js` |
| 計時長度（準備、比賽、維修、靜止倒數）與音效時間點 | `worker/timer.js` |
| 音效 | 換掉 `sounds/*.mp3`（檔名不變） |

**seed 只在資料庫是空的時候使用。** 改完 seed 要換新的資料夾（`DATA_DIR`）或清空 `tel_console` 表，才會用新賽程；人員與通行碼存在 `people` 表，不受影響。

## 設定（環境變數）

| 變數 | 預設 | 用途 |
|---|---|---|
| `PORT` | `3000` | 本機免登入埠（只綁 127.0.0.1） |
| `PUBLIC_PORT` | （不開） | 給 Tailscale 轉入的對外埠，每個請求都要登入 |
| `PUBLIC_HOST` | （不限） | 只接受這個主機名稱的對外請求 |
| `DATA_DIR` | `%LOCALAPPDATA%\tel-robot-combat` | 資料庫、通行碼、備份、紀錄的位置。**不要放在 OneDrive／Dropbox** |
| `VIEW_CODE` | （自動產生） | 指定檢視通行碼 |
| `TEL_TEAMS` | 四隊 | 參賽隊伍，逗號分隔，4 或 5 隊 |
| `SOUNDS_DIR` | 專案的 `sounds/` | 比賽音效的資料夾 |
| `CHROME_PATH` | （自動尋找） | 瀏覽器測試用的 Chrome／Edge 位置 |

## 資料與備份

- 資料庫 `tel-console.sqlite`、檢視碼 `access-codes.json` 都在 `DATA_DIR`。**這兩個檔內含通行碼與成績，不要 commit、不要上傳。**
- 自動備份在 `DATA_DIR\backups\`：每次寫入後最多每分鐘一份，啟動與正常關閉時各一份，保留最近 200 份。還原：停伺服器 → 把備份複製成 `tel-console.sqlite` → 啟動。
- **同一時間只能有一台主控。** 每台電腦的資料庫各自獨立、沒有同步；兩台同時開又各自被修改，成績會分岔。換主控：停舊的 → 拿它最新的備份 → 放到新電腦 → 啟動新的 → 通知大家新網址。
- 改程式時建議比照 2026 年的做法：複製一份「備援」資料夾（不同 `PORT`／`PUBLIC_PORT`／`DATA_DIR`）先改、跑測試與模擬，確認後再套用到主系統，並且**等計時停止再重啟**。

## 測試

```powershell
npm test     # 約 1 分半，會用全新的暫存資料啟動真正的伺服器，不碰正式資料
```

`npm test` 以 `tests/five-teams.env` 的五隊執行（舊測試以五隊撰寫），四隊流程另有 `tests/four-teams.test.mjs`。瀏覽器測試會自動找 Chrome 或 Edge，找不到就跳過。第一次啟動 Chrome 較慢，偶爾會有瀏覽器測試因為時序失敗，重跑即可；若同一項反覆失敗才是真的問題。

| 檔案 | 內容 |
|---|---|
| `tests/scoring.test.mjs` | 計分規則的手算案例（規則有疑義時先改這裡的預期值） |
| `tests/api.test.mjs` | 欄位合併與衝突、並發寫入、完整賽程、權限、指定上場、自動名次、未出賽、移除場次、音效時間點、修改歷史、CSV |
| `tests/four-teams.test.mjs` | 四隊預設賽程從排名賽打到冠軍賽 |
| `tests/auth.test.mjs` | 通行碼名單、檢視碼、登入裝置、停用／重新產生／撤銷、限制嘗試次數 |
| `tests/server.test.mjs` | 真的啟動伺服器：Host／Origin 檢查、登入、權限、OBS 連結、音效檔、自動備份 |
| `tests/browser.test.mjs` | headless Chrome 實際操作：多人衝突、即時計分、指定上場自動跳轉、淘汰賽選邊、移除場次、主審音效、手機版面 |

測試**不包含**真正的 Tailscale Funnel、iPhone／Android／LINE 內建瀏覽器與現場網路，比賽前請用實機走一次。

## 原始碼

| 檔案 | 內容 |
|---|---|
| `server.mjs` | Node HTTP 伺服器：本機埠、對外埠、登入、OBS 連結、音效檔、SQLite、自動備份 |

| `worker/overlay.js` | 直播字卡 |
| `worker/ui.js` | 控制台與觀賽畫面的 HTML、CSS |
| `scripts/` | 音效下載、Windows 看門狗與開機啟動 |
