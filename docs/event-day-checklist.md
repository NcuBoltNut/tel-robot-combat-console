# 比賽當天操作清單

給總召與主審。每一項都在 2026 年實際走過。

## 比賽前幾天

- [ ] 改 `worker/event.js`（名稱、日期、主辦、字卡文字）與 `worker/seed.js`（隊伍、賽程時間），用**新的資料夾**啟動一次，確認賽程正確。
- [ ] `npm test` 全部通過；`node scripts/fetch-sounds.mjs` 下載音效。
- [ ] 本機開「人員與登入」，為每位工作人員建立個人通行碼：主審與總召（主裁判／總召）、計分 A／B（計分）、攝影（攝影）。私訊給本人。
- [ ] 開 Funnel 拿到網址，寫進工作人員與參賽者的行前通知；觀眾用的檢視碼也一起附上。
- [ ] 主控電腦：插電、關掉睡眠與休眠；資料夾不要放在 OneDrive。需要的話設定開機自動啟動（README「開機自動啟動」）。

## 當天開賽前

- [ ] 工作人員集合時全部登入（登入維持 16 小時）。
- [ ] 主審在「比賽計時」頁點一下畫面，確認最下方「播放比賽音效」有勾。
- [ ] 計分員打開一場淘汰賽，在計分視窗上方選好「我負責 A 方／B 方」（手機會記住）。
- [ ] 現場接音響的電腦開觀賽畫面，按右上角「🔇 開啟聲音」。
- [ ] 攝影在 OBS 加瀏覽器來源 `https://<網址>/obs/<攝影通行碼>`，1920×1080，確認去背與音量。
- [ ] **設備測試**：主審指定一場上場 → 計分員畫面自動跳過去 → 點幾下 → 觀賽畫面與字卡出現暫定分數 → 準備／比賽計時與音效正常。
- [ ] 測完由主審在每一場按「⟲ 分數歸零」清掉測試資料，並按「重設計時」。

## 每一場

1. 主審：「上場」選單選隊伍（排名賽）或場次＋兩隊（淘汰賽）→ **📣 指定上場**。
2. 主審檢錄後按 **① 調整準備 90 秒** → **② 開始比賽 3 分鐘**。
3. 計分員即時點擊；排名賽投完 27 球舉完成卡時主審按 **✓ 完成**。
4. 結算、處理異議、隊伍簽認 → 主審在計分視窗填簽認，成績改「已確認」。
5. 淘汰賽勝隊：主審按 **晉級隊維修 5 分鐘**（不影響「在場上」的場次）。

## 突發狀況

| 狀況 | 做法 |
|---|---|
| 某隊沒來 | 那隊排名賽「裁判判決」選 **未出賽** 並確認；淘汰賽碰到時缺席方也選未出賽，對手不戰而勝 |
| 某場不比了 | 主審在「計分與影像」按 **移除場次**（可復原） |
| 點錯分數 | 計分員按「−1」或「復原上一步」；已確認的成績只有主審能改，或按「分數歸零」重來 |
| 完全同分 | 名次留白，主審抽籤後手動填，備註寫「主裁抽籤」 |
| 手機遺失／通行碼外流 | 「人員與登入」對那個人按 **重新產生**（或 **停用**） |
| 伺服器當掉 | 看門狗 5 秒內自動重開；計時狀態存在資料庫，接得上 |
| 主控電腦壞掉 | 停用它 → 取 `backups\` 最新備份到另一台 → 啟動 → 開 Funnel → **通知大家新網址** |

## 比賽後

- [ ] 「計分與影像」右上角 **下載成績 CSV** 存檔。
- [ ] 複製 `DATA_DIR`（資料庫與備份）到安全的地方留存。
- [ ] 關閉 Funnel：`tailscale funnel --https=10000 off`；取消開機自動啟動（刪掉「啟動」資料夾裡的捷徑）。
