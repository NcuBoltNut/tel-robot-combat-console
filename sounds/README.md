# 比賽音效

伺服器從這個資料夾提供四個音效（`/sounds/<名稱>.mp3`），觀賽畫面、主審控制台與直播字卡在計時跨過時間點時播放：

| 檔名 | 何時播放 |
|---|---|
| `start.mp3` | 調整準備 90 秒開始、正式比賽 3 分鐘開始 |
| `resume.mp3` | 正式比賽第 60 秒（AI 自主控制結束、切換手動） |
| `warning.mp3` | 剩 30 秒（準備與比賽都會） |
| `end.mp3` | 時間到，或主審按「完成」 |

2026 年用的是 FRC 場地音效（第三方著作），**不放進 git**。新環境執行一次即可下載：

```powershell
node scripts/fetch-sounds.mjs
```

要換成別的音效，把 mp3 用上面的檔名放進來就好。缺檔時伺服器回 404，畫面照常運作，只是沒有聲音。
